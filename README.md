# MKCC Prints v1.2.3.11

Craft-show inventory cleanup and assignment workflow.

- Craft-show inventory is tied to specific events.
- Stock Prints no longer exposes a generic "Send to Show" workflow.
- Use "Assign to Show" to assign stock to an open Craft Show.
- Existing unassigned craft-show quantities can be assigned to an event.
- Stock editing preserves existing craft-show quantities without allowing orphaned manual changes.
- No photos or Firebase Storage.
